LAUERTRUCKER – Büro/Admin Testversion

Diese Version basiert auf der Login-Demo und enthält zusätzlich:
- Büro/Disposition
- Fahrer anlegen und verwalten
- Fahrzeuge anlegen und verwalten
- Benutzer & Rollen verwalten
- Auftragsübersicht im Adminbereich
- Dashboard-Zähler für Fahrer, Fahrzeuge und Aufträge
- Login-Demo: lauer / trucker2026

WICHTIG:
Die Daten werden in diesem Test lokal im Browser (localStorage/sessionStorage) gespeichert.
Das ist noch keine echte zentrale Benutzerverwaltung und keine sichere Server-Anmeldung.
Wenn du die App auf mehreren Geräten synchron nutzen möchtest, brauchen wir später eine echte Datenbank/Anmeldung.

TEST:
1. ZIP entpacken bzw. die Dateien in dein GitHub-Pages-Repository hochladen.
2. Seite öffnen.
3. Mit lauer / trucker2026 anmelden.
4. Unten „Admin“ öffnen.
5. Fahrer, Fahrzeuge und Benutzer anlegen.
6. Unter „Büro“ Aufträge anlegen und unter „Admin > Aufträge“ prüfen.
